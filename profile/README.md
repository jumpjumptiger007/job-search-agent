# Candidate setup (private)

Place your factual `profile.yaml` here. It is intentionally git-ignored.
The profile is the source of truth: generated documents may only rephrase, select, and reorder facts from it.

Required before material generation: factual profile and a validated job analysis/tailoring plan. Discovery/search setup separately requires private discovery preferences.

`profile.yaml` must at minimum contain a factual `name`. Optional factual fields are `email`, `phone`, `location`, `summary`, `skills`, `experience` (employer/title/dates/bullets), and `education`. This file is private and ignored by Git.
