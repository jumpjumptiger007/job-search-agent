Gate 7 removes the active `lib/job-artifacts.ts::writeJobFiles()` path, its `lib/job-store.ts` ingestion calls, and the `lib/jobs.ts` compatibility export. Ingestion and BA `INSUFFICIENT → SUBSTANTIVE` upgrades now update SQLite only; they retain the deterministic SQLite `folder_path` without creating a job directory. `generateMaterials()` remains the on-demand creator of application artifact directories and the Gate 6 artifact set is unchanged.

`npm run cleanup:legacy-job-files` is an explicit, idempotent maintenance command. It respects `JOB_AGENT_STORAGE_ROOT`, touches only root-level `job.json`, `jd_original.md`, and `analysis.md` in direct `jobs/` child directories, and removes a directory only when it is empty afterward. It does not open or modify SQLite and leaves all other files and directories alone.

Architecture and workflow documentation now state the final ownership rule: SQLite owns operational state; job folders hold generated or user application artifacts, not SQLite mirrors.
