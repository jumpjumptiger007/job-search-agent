- Preserved richer factual text obtained from the existing shallow direct-careers/web resolution path, with safe fallback when the source cannot be fetched.
- Preserved job-specific direct-careers URLs during enrichment instead of replacing them with generic careers-navigation links, and re-applied the existing deterministic preference gate after enrichment before ingest.
- Added the approved deferred `POST_V0.6_ROADMAP.md` planning context to the repository; it remains explicitly outside implementation scope.
- Updated package version and changelog to `0.6.0`.

No new providers, crawling, browser automation, runtime AI, scoring redesign, tailoring redesign, or application submission behavior was added.
